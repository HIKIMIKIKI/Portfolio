# Project Report

## Project Title
Full-Stack Student Portfolio Website

## Student Summary
This project is a personal portfolio website designed to present my skills, academic background, and projects in a professional way. It combines frontend and backend technologies taught during the semester.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- PHP
- MySQL
- AJAX with Fetch API

## Main Features
- Semantic HTML sections for home, about, projects, skills, and contact
- Responsive layout using Flexbox and Grid
- JavaScript dark mode toggle and dynamic text rotation
- JavaScript form validation before submission
- Contact messages saved into a MySQL database
- Portfolio projects loaded from the database without refreshing the page
- Session-based admin login and a cookie for last login tracking
- Admin dashboard to add, edit, and delete projects

## Database Tables
- `admins`
- `projects`
- `messages`

## Testing Summary
Frontend structure and logic were reviewed in the project files. PHP and MySQL command-line tools were not available in the current environment, so full runtime testing should be completed in XAMPP, WAMP, or another PHP server before final submission.
